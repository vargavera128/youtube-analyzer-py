# youtube-analyzer-py

This Python program is part of the YouTube Comment Analyzer project. It is responsible for performing sentiment analysis on YouTube comments, classifying them into positive, neutral, or negative categories.

# how to run

1 - Execute the following command in your terminal to download the requirements: pip install -r requirements.txt
2 - Run the program by the following command: uvicorn sentiment_api:app --host 127.0.0.1 --port 8001
